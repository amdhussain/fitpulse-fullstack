# 🏋️ FitPulse – Fitness Booking Platform

A modern full-stack Fitness Booking Platform built with **React.js**, **Node.js**, **Express.js**, **MongoDB (Native Driver)**, and **Better Auth**. The platform allows users to register, log in, book fitness sessions, manage memberships, and provides an Admin Dashboard to manage users, trainers, bookings, payments, and website content.

